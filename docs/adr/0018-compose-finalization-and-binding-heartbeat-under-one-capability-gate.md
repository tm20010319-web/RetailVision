# Compose Finalization and Binding Heartbeat Under One Capability Gate

The Store Runtime reads one startup-only Phase 2B capability gate that jointly enables the Job producer, one dedicated Finalizer thread, and one dedicated Binding lifecycle heartbeat thread in new mode; disabled production neither constructs consumers nor mutates existing facts. Finalization exclusively drives claim through completion, heartbeat exclusively maintains already-active Binding lifecycle, and Association Outcome Projection remains separate. Both workers share the Runtime's single snapshot buffer and identity Cache, renew long-running claims where required, report lease loss and persistent integrity failure through distinct signal-only fatal channels, and cross a shutdown barrier before Runtime-scoped Cache cleanup and fenced Lease teardown.
