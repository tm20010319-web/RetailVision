# Mount display cameras for behaviour observation

Display-area cameras will use an oblique downward view that keeps customers' upper bodies, arms, and merchandise displays visible. A purely top-down view was rejected because it supports traffic counting but makes Merchandise Reach unreliable through foreshortening and occlusion.

## Consequences

- Final mounting is validated against real frames before Merchandise Display Areas are calibrated.
- The target installation is approximately 2.2-2.8 metres high with a 30-45 degree downward angle, adjusted for the actual lens and furniture.
- Camera movement after calibration requires the affected areas to be calibrated again.
